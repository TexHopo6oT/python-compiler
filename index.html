      🌐 Локальная сеть Python IDE (Сервер и Клиент)
      
    


    

      
      
    


    

      

        

          Запустите локальный сервер python_studio_server.py на своём компьютере, чтобы другие устройства в локальной сети могли открывать интерфейс IDE, синхронизировать код и выполнять скрипты через ваш системный интерпретатор Python 3.
        


        

          
          
          
          
        

        

          
          
        


        

          
          
        


        
1. Положите HTML-файл IDE и python_studio_server.py в одну папку.
2. Запустите в терминале: python3 python_studio_server.py --port 8085
3. Клиенты в локальной сети открывают: http://<IP-вашего-ПК>:8085

      


      

        

          Подключитесь к запущенному серверу python_studio_server.py по IP-адресу в локальной сети (или к локальной хост-сессии этого браузера) для совместной работы и выполнения кода через системный python3.
